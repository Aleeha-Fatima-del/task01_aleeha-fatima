Project Overview
This repository contains the Week 1 Data Analytics project. It demonstrates basic data exploration and analysis using Jupyter Notebook.

Contents
Dataset for Data Analytics (1).xlsx → Raw dataset used for analysis

Week__1_project.ipynb → Jupyter Notebook with step-by-step analysis

Week_1 project Report.pdf → Formal project report summarizing findings

README.md → Documentation file

Tools & Languages
Python (via Jupyter Notebook)

Libraries: Pandas, NumPy, Matplotlib

How to Run
Clone the repository

Open Week__1_project.ipynb in Jupyter Notebook

Install required libraries (pip install pandas numpy matplotlib)

Run cells sequentially to reproduce results
